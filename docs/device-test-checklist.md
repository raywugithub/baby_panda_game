# 熊貓成長記：女兒的 iPhone 實機測試清單

給爸爸媽媽用的測試表。請在女兒的 iPhone（iOS 16.4 以上）上，照順序一項一項做。
自動化測試只能當作迴歸檢查，真的手機上的觸控、捲動、音效和離線行為，還是要實際點過才算數。

**怎麼用：**
- 每一項做完就在 `[ ]` 打勾（改成 `[x]`）。
- 「結果」那一行寫下看到什麼：正常就寫「正常」，有問題就寫現象（例如「點不到右下角按鈕」），並附上大概的時間與機型。
- 遇到問題先不要急著刪除資料，記下來再回報。
- v1 不會把照片存到手機的相簿，照片只會留在遊戲的相簿裡，這不是缺陷。

## 測試矩陣

**完整清單在兩種情境各測一次：**「Chrome 分頁」與「從 Chrome 加入主畫面」。這兩種是正式測試，每一項都要做。

| 情境 | 說明 | 範圍 |
| --- | --- | --- |
| Chrome 分頁 | 用 Chrome 打開遊戲網址，直接在分頁裡玩。 | 全部項目 |
| 從 Chrome 加入主畫面 | 用 Chrome 打開網址 → 分享 → 加入主畫面，再從桌面的圖示打開。 | 全部項目 |
| iOS Safari 分頁 | 用 Safari 打開網址。 | 只做標示 `★` 的項目（★Safari） |

每個項目格式：`[ ] Chrome 分頁　[ ] 主畫面 App`；標示 `★` 的項目，另外多一格 `[ ] ★Safari 再測一次`，要在 Safari 裡再做一次。
